A modern creative agency website inspired by K72 and built with a strong focus on visual storytelling, smooth interactions, and minimal design.

The project explores how thoughtful layouts, typography, imagery, and animation can come together to create an engaging web experience.

Design reference: K72
Visual inspiration: Anima

✦ About The Project

This website was created as a frontend design and development project with the goal of recreating the feel of a modern creative agency website.

Instead of focusing only on traditional layouts, the project uses movement, transitions, large visuals, and interactive sections to make the website feel more dynamic and immersive.

The main focus was on making the experience feel clean, modern, and visually engaging.
